# Animal Database Management System

A Java-based database management application for managing animal records using JDBC and MySQL.

## Features

- Add animal records
- View all records
- Search animals by ID
- Delete records
- MySQL database connectivity
- JDBC integration

## Technologies

- Java
- JDBC
- MySQL
- SQL

## Database Setup

Run the database.sql file in MySQL.

Update the MySQL username and password in:

AnimalManagementSystem.java

## Run

Compile:

javac AnimalManagementSystem.java

Run:

java AnimalManagementSystem
